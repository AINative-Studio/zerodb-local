# Support

Thanks for using ZeroDB Local! Here's how to get help.

## Documentation

Start with the [README](./README.md) and [docs/](./docs/) for setup,
configuration, and architecture. [docs/TROUBLESHOOTING.md](./docs/TROUBLESHOOTING.md)
covers common issues (port conflicts, container recreate, auth mode, etc.).

## Reporting a bug or requesting a feature

Open an issue in this repo's own tracker:
[github.com/AINative-Studio/zerodb-local/issues](https://github.com/AINative-Studio/zerodb-local/issues).

Before filing, please check whether an existing open issue already covers
it. For a bug, include:

- What you ran (the exact command or `docker compose` invocation)
- What you expected to happen
- What actually happened (full error output, not just the last line)
- Your OS and Docker/Docker Compose version
